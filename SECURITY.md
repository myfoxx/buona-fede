# Segnalazioni di sicurezza

Questo repository contiene testi: un manifesto, schede comparative, una proposta di legge in bozza e un sito statico. Non contiene software in esecuzione e **non riceve segnalazioni di vulnerabilità**, né sue né di terzi.

Se hai trovato una vulnerabilità in un sistema, non scriverlo qui, in nessuna forma: usa i canali di CSIRT Italia. Il repository non offre consulenza legale sulla tua posizione: per quella serve un avvocato.

Un contenuto che descriva una vulnerabilità reale non risolta viene rimosso dalla segreteria senza commento, come previsto dal [Codice di condotta](CODE_OF_CONDUCT.md).

Per errori nel sito (link rotti, problemi di accessibilità) apri una issue o scrivi a segreteria@buonafede.org.
